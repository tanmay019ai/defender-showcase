# 🚗 Defender Showcase

An immersive 3D web experience showcasing the **Land Rover Defender**, built using modern frontend technologies.  
This project combines cinematic visuals, smooth animations, and a responsive UI.

---

## ✨ Features

- 🌟 Interactive 3D Defender model
- 🎥 Smooth camera movements & animations
- 🎨 Modern UI with Tailwind CSS
- 📱 Fully responsive design
- 📬 Enhanced contact options
- ⚡ Fast performance with Vite

---

## 🛠️ Tech Stack

- **React**
- **Tailwind CSS**
- **Three.js**
- **Vite**
